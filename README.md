# KESMO Pricing Calculator

**Precision made simple.**

A free browser-based pricing calculator that helps estimate selling prices based on costs, transaction fees, fixed fees, and target profit margins.

## Live Website

https://kesmoworks.github.io/pricing-calculator/

## Features

- Calculate suggested selling prices
- Target profit margin support
- Percentage transaction fees
- Fixed transaction fees
- Break-even price
- Profit calculation
- Markup calculation
- Maximum discount before loss
- Copy Results button
- Mobile-friendly responsive design
- No account required
- Runs entirely in your browser

## Why I Built This

Pricing products correctly can be surprisingly difficult once marketplace fees, payment processing, and desired profit margins are included.

The KESMO Pricing Calculator makes those calculations simple and transparent.

## Privacy

This calculator runs entirely in your browser.

No calculator entries are stored or transmitted.
